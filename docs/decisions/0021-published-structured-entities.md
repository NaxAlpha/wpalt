# 0021 — Publication-bound structured entities

Date: 2026-10-11. Status: accepted implementation design within the authorized D07 backlog.

Bind known named schema entities/properties to the same native typed fields, factual publication attributes and admitted relationships/assets used by authoring and themes. Extend existing Studio model editing rather than introduce a separate raw-JSON schema-content database. Emit and display one bounded projection, with current public-resource policy and no inferred private account facts. Explicit configuration is immediate administrator model policy; content values remain published snapshots.

Use an attributed pinned offline Schema.org registry and bounded native search, parsing only for enabled declarations/search. Keep vocabulary status and application binding admission separate from dated provider recommendation reports; neither implies rich-result/indexing eligibility. Preserve fixed identity cycles under visited/budget constraints rather than reject legitimate JSON-LD references. No runtime remote contexts, scripts or unbounded ontology loading.

Native 21 / portable v17 fence the new persisted model grammar. Stopped maintenance and explicit conversion preserve old original-runtime recovery; reject new graph keys through every falsely old source marker. No permanent old-runtime parser branch. The [contract](../d07-contract.md) defines end-user journeys and initial limits to verify/measure.
