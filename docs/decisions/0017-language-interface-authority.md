# ADR 0017: Separate interface, content and translation-proposal authorities

Date: 2026-10-07. Status: accepted implementation direction; persistence/migration and long-document proposal implementation remain pending D03 verification.

Each account's interface preference selects a supported bounded local catalog. It does not modify configured public languages, post locale, translation group, routing, SEO, access or publication. Persist it in a dedicated user-keyed preference relation with a monotonically increasing version; do not repurpose biographies or treat a browser cookie as durable account authority. Current-session authority and CSRF protect changes. Changing preference cannot grant capabilities. Account erasure and portable recovery must include its appropriate behavior.

The native schema 17 / portable v13 base has no preference relation. Adding it requires native schema 18 and portable v14 with an explicit stopped upgrade and offline v13 converter, preserving original pre-change recovery bytes. Old runtime fallback is not added. Existing older recovery retains its explicit conversion path; target graph validation must remain complete. A language-workspace pagination index belongs to the same native migration, with real SQLite/PostgreSQL plans and populated-page verification.

The catalog is a versioned bundled asset with stable message IDs, a declared translation inventory, escaped parameters, plural/count grammar and local formatting. Initial English/French/Japanese/Arabic messages have scoped coverage and require connected UX review. Untranslated sections declare English; changing shell language does not falsely declare all English text translated. Content comparisons preserve their own language/direction; mixed-direction names/identifiers are isolated. Runtime network catalogs are unnecessary.

Manual copy/synchronization uses the actual writer, shared mutation boundary and exact saved source/target material. Protected values cannot move into a weaker target policy. An operation creates or edits a draft with D02 review invalidation and native revisions/events; it cannot silently publish or synchronize unrelated author-controlled text/discovery/access.

Long-document model translation is a separate proposal over bounded canonical text segments, not Markdown regeneration of rich content. Keep structure, attributes, node identities, code, links, media and form references outside model authority. Source revision and canonical document digest bind preview/apply; complete validated replacement sets prevent partial silent application. A private recoverable proposal may resume failed model work, but model/worker publication authority is absent. Actual model quality evaluation reports factual/language failures and human editing requirements; successful JSON/structure cannot establish translation accuracy.
