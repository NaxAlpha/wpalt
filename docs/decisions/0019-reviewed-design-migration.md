# 0019 — Reviewed design migration into shared native composition

Date: 2026-10-10. Status: accepted within the authorized D05 contract.

Elementor exports describe a different layout/widget runtime. Import bounded source data through an independent compiler into existing package-2 nodes; do not execute source PHP, raw CSS, JavaScript or fetch external assets. Use admitted owner mappings and report every unmapped source property. Preserve content-only projection as a separately labeled outcome. Atomic typed settings are interpreted explicitly, while their raw styles/interactions remain reported until a safe semantic mapping has evidence.

A review binds the source, mappings, placement, current base version and resulting package/report. Applying it recomputes the review and requires its exact fingerprint and explicit loss acknowledgement; the existing current-owner/versioned theme transaction saves only a private draft. A specific-content placement uses an explicit native post-ID condition and preserves the previous model template for other content. Header, footer and home replacement require explicit targets; reusable component placement is the default. Existing publication, local assets, validation and recovery remain authoritative.

No persisted schema change is needed merely to add this compiler/workflow. Native node/depth/byte limits are retained and invalid oversized output is refused before writes. Runtime dependency and full source breadth remain in the inventory/backlog rather than being described as complete parity. Source inspection is distinct from current-free-plugin execution, which belongs to a dedicated disposable Linux container reference gate.
