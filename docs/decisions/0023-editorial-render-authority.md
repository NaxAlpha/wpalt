# 0023 — Durable rendering authority for editorial analysis

Date:2026-10-12. Accepted implementation decision within the authorized D09 scope after D08 delivery verification. Select a durable database epoch changed transactionally by a precise inventory of public rendering dependencies. General request/cache generations are unsuitable: scheduled publication acquires mutation authority on empty cycles, and ordinary unrelated work would starve multi-batch scans. A timestamp alone misses same-second changes, deletion/recreation and restart boundaries; a full-site hash on every small batch repeats body loads. A trigger-based epoch covers native and controlled direct database writes, participates in source transaction rollback, costs one indexed singleton update on relevant source changes, and survives worker/application restart.

The inventory covers published post payload/status, public site settings/models/discovery, live theme/shared options, exact/capture/owned redirect policy, public media metadata/access, member-resource restrictions, taxonomy relations/names and approved comments. Ignore working-only post edits, draft-only theme/options edits, pending comments, 404 counters, analytics, mail/orders and empty worker cycles. Where a dependency has no public/draft distinction, invalidate conservatively. The native render input inventory and tests must grow with future public sources; there is no universal automatic semantic dependency detection.

Use SQLite and PostgreSQL-native trigger syntax under the same behavioral contract. Integer overflow aborts the source transaction rather than reusing an epoch. A worker reads the epoch before/after bounded source or classification work and commits progress only under the unchanged epoch. Final completion uses the epoch row as database write authority so a publication/permission transaction cannot commit a source change without invalidating the result. Cancellation/CAS prevents a late worker from reviving a cancelled job. Stale results expose no stored source/title/link/keyword observations; owners can remove/retry them explicitly.

Derived job/page/result tables are private operational cache, omitted from portable content recovery; new/fresh restored sites rebuild rather than trust old analyses. Retain a finite number of runs and bound aggregate HTML, edges and serialized derived data. Define interruption/retry boundaries precisely; use database CAS, not a process-local mutex as the sole worker ownership mechanism. Native schema changes to 23; portable grammar may remain v18 if archived content semantics/table set are unchanged. Prove authentic native22 upgrade/fresh rollback and fresh portable recovery, and document this independent numbering decision.

Normal HTTP/worker local-process admission and in-process mutation locks keep native rendering coherent during each batch. Database epoch checks additionally fence independent App instances used in concurrency tests. A result describes its recorded public rendering snapshot and declared route families. Manual filesystem corruption/external SQL that disables triggers and arbitrary client CSS/layout are not certified live-state mechanisms; current private access and media availability remain checked through the authoritative APIs.

The private rendering identity includes the exact executable digest, declared segmentation/NFC/Rust lowercase versions, relevant public configuration and consent manifest. A changed executable invalidates old result semantics even without a schema change; code fixes cannot silently reuse an earlier parser or completed route classification. The host hashes its executable once with the existing bounded process-coordination helper. First-use hashing is included in started-run observations; it is not isolated from renderer/database/startup cost, and is not repeated per source/batch. Different compiler builds also conservatively require a fresh run.

HTTP owner writes recheck the current role/session under mutation authority; manual batch advancement checks the requested run/version there too. Selected-copy observations recheck before revealing text. Fresh admission transactionally fences obsolete unfinished work before opening another run. Missing source ordinals fail the batch instead of advancing a misleading cursor. Generic stopped CLI/worker primitives keep their trusted host boundary.
