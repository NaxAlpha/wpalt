# M3.5 — Integrated content authoring

Approved scope, 2026-10-02. Status: specification; not an implementation/parity claim.

## End-user system

A calm direct writing canvas supports paragraphs, headings, lists, quotes, callouts, code, images and basic tables; inline marks/links; slash insertion and conversion; duplication; keyboard and drag movement. Offer contextual formatting, useful safe paste, undo/redo and clear save status. Writing is the primary surface; language, SEO, typed fields and publishing use progressive disclosure.

Preserve draft/live isolation, scheduling, authorizations, autosave, optimistic conflicts, revisions, previews, backups and owner-controlled offline runtime. A versioned structured document supplies editing and public rendering, with safe bounded server validation. Meaningful Markdown, publication snapshots and historical revisions migrate explicitly; provide migration/recovery notes and current-format exports. Do not silently discard unsupported source data.

## Working sequence

1. Record the editor/document architecture and affected guidance. Implement the validated document, renderer and one-off migration first.
2. Deliver the direct editor, block/formatting operations and accessible insertion/organization controls.
3. Integrate save/history/recovery, media, language/SEO and publication flows.
4. Verify and optimize individual operations and complete illustrated multilingual authoring journeys, then deliver the milestone PR and verified clean artifact.

## Completion evidence

Readable clusters verify selection/cursor and undo behavior, typing and multilingual composition, sanitized paste, keyboard/drag reordering, reload/interruption and failed saves, stale writers, publication/schedule isolation, revision restore and fresh backup recovery. Exercise real SQLite/PostgreSQL and real browsers; extend precise UI contracts with intentional visual review. Measure realistic long documents and asset/request footprints, not a million shallow toolbar assertions. Record supported browser/input limits and untested assistive technologies honestly.

M4–M6 contribute workflow blocks; M8 handles supported imports/extension-author tooling; M9 owns broader release hardening. Real-time coediting, offline synchronization, Notion databases/workspaces and automatic translation are outside this approved authoring milestone.

Reference interaction basis: https://www.notion.com/help/writing-and-editing-basics. Verify current editor-engine, web input and accessibility primary guidance before implementation; record the maintenance mappings in the evidence manifest.
