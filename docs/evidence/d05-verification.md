Source popup/template behavior, raw styles, dynamic references, conditions, animation and unsupported controls never become native execution or access rights. Literal Markdown/encoded HTML, adversarial link destinations and code-fence delimiters cannot create new inline image requests; inline images are omitted with explicit losses and existing asset visibility applies to mapped image widgets.
